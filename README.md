# Fitfinity Staff PWA Preview v0.20

Mobile UI refinement build for owner/trainer portal testing.

## v0.20 changes
- Owner trainer-detail tabs now use the same sizing/spacing as the client-detail tabs.
- Assigned Clients inside an owner trainer profile now uses a tidy aligned Client / Package / View layout.
- Trainer account/profile no longer contains an Assigned Clients tab; it keeps Overview and Availability only.
- Top-left Back arrow now returns to the actual previous in-app page using the logical portal navigation stack and restores that page's scroll position.
- Removed the visible swipe/back indicator arrow from the lower-left/edge of the page. Swipe-right navigation remains available without the floating indicator.
- PWA cache bumped to v20.

This remains a static prototype. Do not enter real client data until the secure backend and RBAC are connected.
