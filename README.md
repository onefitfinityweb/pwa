# Fitfinity Staff PWA — v0.16

Mobile UI testing build. This remains a static prototype and must only use dummy data.

## v0.16
- Every user-facing HTML dropdown in the staff portal now uses a consistent in-app searchable picker rather than Android's native full-screen select UI.
- Search field, current-selection highlighting, and a visible top-right close button are standard across filters and forms.
- Dynamic trainer/options dropdowns are enhanced automatically when their options are generated.
- Disabled/read-only dropdowns remain disabled.
- The exercise selector keeps its dedicated searchable exercise picker because it supports exercise categories and Custom Exercise.
- Date and time inputs remain Android-native because the system date/time pickers are more appropriate than a generic option list.
- PWA cache bumped to v16.
