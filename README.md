# Fitfinity Staff PWA Preview v0.9

Mobile-first UI prototype for testing the Fitfinity owner/trainer staff workflow before backend integration.

## v0.9 changes

- Client Profile top identity card is substantially smaller on mobile.
- The four package summary cards now use the same compact visual density as the Session Details summary cards.
- Owner Session Management is now a compact action strip with smaller controls instead of a large panel.
- Completed sessions remain locked and continue to hide Owner Session Management.
- Service-worker cache bumped to v9.

## Prototype limitations

This is still a UI/PWA prototype. Login, password changes, database persistence, file storage, video processing, WhatsApp delivery, Glofox and backend RBAC are not live yet. Use dummy data only.
