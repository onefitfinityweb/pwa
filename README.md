# Fitfinity Staff PWA Preview v0.18

UI refinement build for mobile testing.

Changes in v0.18:
- Session edit controls no longer overlap the Session Details heading on mobile.
- Session acknowledgement and WhatsApp actions occupy a centered 50/50 row.
- Owner remuneration month view shows correct overall totals; trainer View actions stay at the right.
- Trainer main edit includes name and excludes rates.
- Trainer rates have a separate Edit / Save / Cancel flow; the new effective-date field only appears when a rate actually changes.
- Assigned Clients removed from Trainer Profile and added as its own owner navigation page with trainer, search and type filters.

Prototype only: no real authentication, persistence, uploads or WhatsApp delivery tracking yet.
