# Fitfinity Staff PWA Preview v0.5

Mobile UX prototype for owner/trainer testing. Dummy data only — authentication and backend persistence are not production-ready yet.

## v0.5 changes
- Exercise Library now fits the mobile viewport without horizontal scrolling; less-important media/status columns collapse on phone.
- Client onboarding package choices corrected to 12-session PT and 24-session PT only.
- Couple remains a client-type choice and only reveals the second person's fields.
- Added Single Day / Double Day weekly frequency.
- Fixed recurring day/time slot(s) must be explicitly locked before trainer matching and client creation.
- Double Day automatically includes the free gym membership.
- Auto-filtering now requires one trainer to cover every locked weekly slot.
- Ad-hoc rescheduling remains separate from the client's locked recurring weekly schedule.

Deploy the files in this folder to the GitHub Pages repository root.
