# Fitfinity PWA Preview v0.19

Mobile UI refinement build for owner/trainer testing.

Key changes:
- Assigned Clients moved into each trainer detail as a tab for owner and trainer views.
- Client profile wording cleaned and package labels simplified.
- Trainer name is no longer editable.
- Owner trainer availability now matches the trainer account compact availability style.
- Mobile back-arrow cue added beside the hamburger; swipe-right back remains available.
- Session Details top summary is enforced as 2×2 on mobile.
- Upcoming Renewals View All is pinned top-right, client count removed, and close/back restores dashboard scroll.

Prototype only: use dummy data until backend authentication and persistence are connected.
