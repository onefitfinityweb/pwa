# Fitfinity Staff PWA Preview v0.4

Phone-first UX preview for the Fitfinity owner/trainer portal.

## v0.4 changes
- Compact mobile statistics on Clients, Sessions, Remuneration and trainer activity areas.
- Internal portal navigation now uses real `#portal/<screen>` fragment history entries for better Android/Chrome standalone Back-button behaviour.
- Retains v0.3 phone-width tables and the revised exercise editor/automatic client summary.
- Service-worker cache bumped so installed PWAs can refresh to this build.

## Important
This is still a static UI prototype. The current demo login is **not production authentication** and no real client data should be entered yet.
